# Kiki — Personal Portfolio

Website portofolio sederhana menggunakan HTML, CSS, dan JavaScript.

## File
- `index.html` — struktur dan konten website
- `style.css` — tampilan dan responsive layout
- `script.js` — menu mobile, animasi reveal, dan tahun footer

## Cara menjalankan
Buka `index.html` di browser. Pastikan ketiga file berada di folder yang sama.

## Publikasi dengan GitHub Pages
1. Buka repository GitHub.
2. Pilih **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.

## Sebelum dipublikasikan
- Ganti `emailkamu@example.com` di `index.html` dengan email aktif.
- Tambahkan tautan LinkedIn/GitHub bila ingin ditampilkan.
- Periksa kembali deskripsi proyek agar sesuai dengan proyek yang benar-benar pernah dibuat.
- Perbarui detail pengalaman PKL sesuai kegiatan yang benar-benar dilakukan.
